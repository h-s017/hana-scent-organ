# H.Fugue 調香台 Organ App

這是獨立調香台 PWA App 版本。

## GitHub Pages 上傳方式
1. 建立新的 GitHub repository，例如 `hfugue-organ-app`。
2. 將本資料夾內所有檔案上傳到 repo 根目錄。
3. Settings → Pages → Deploy from a branch → main / root。
4. 開啟 GitHub Pages 網址。

## 手機安裝
- iPhone / iPad：用 Safari 開啟網址 → 分享 → 加入主畫面。
- Android：用 Chrome 開啟網址 → 安裝應用程式或加入主畫面。

## 送出資料
`config.js` 已設定 Apps Script Web App URL。
